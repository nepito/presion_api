# API de Monitoreo de Presión Arterial 🩺❤️

API RESTful robusta y fácil de usar, construida con FastAPI y Pydantic, diseñada para potenciar aplicaciones de salud.

Esta API permite a usuarios y profesionales registrar, consultar y gestionar lecturas de presión arterial de manera segura y eficiente. Su propósito es servir como el motor para aplicaciones dedicadas al monitoreo proactivo de la salud cardiovascular, similar a herramientas como "App Corazón Sano".

Es la solución ideal para desarrolladores que buscan construir la próxima generación de aplicaciones de e-health, fomentando el cuidado personal y proporcionando una herramienta valiosa para el seguimiento médico.
